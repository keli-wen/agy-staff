# agy-staff 0.5.1 — Sandbox Liveness & False Crash Guard

Release date: 2026-09-04.

## Highlights

- **Avoid false crash reports across harness sandbox boundaries (#11).** When `wait`, `status`, or `result` is run from a sandboxed command context while a background worker was launched unsandboxed (e.g. in Codex Desktop or other container/permission environments), the collector process could fail its liveness check (`pidAlive=false`) because the worker PID is not visible across the sandbox boundary. The companion now recognizes this pattern and outputs an actionable, harness-neutral diagnostic warning:
  `The worker pid is not visible from this process. If the job may have been started from a different harness permission or sandbox context, rerun wait/status/result from the same unsandboxed context before treating it as crashed.`
- **Liveness self-healing.** If a collector previously marked a job `crashed` in `state.json` due to an inaccessible PID from inside a sandbox, subsequent calls from an unsandboxed context where the worker PID is visible automatically restore the job's status to `running` (or to `done` if the worker finished and wrote its result file).
- **Clear harness permission documentation.** Updated all persona skills (`researcher`, `reviewer`, `implementer`, `staffer`), `jobs`, and reference documentation to emphasize that job management commands (`wait`, `status`, `result`, `cancel`) should run in the same unsandboxed permission context as the background job start.
- **Pi agent package synchronization.** Maintained alignment across package metadata, generated Pi skills (`pi-skills/`), and Pi packaging and compatibility checks with plugin manifests.

## Upgrading

Both Claude Code and Codex cache the plugin per-version; update and restart the harness so the new version loads:

```bash
claude plugin marketplace update agy-staff && claude plugin update agy@agy-staff   # then restart Claude Code
```

```bash
codex plugin marketplace upgrade && codex plugin add agy@agy-staff                 # then restart Codex
```

For Pi:

```bash
pi update --extension git:github.com/keli-wen/agy-staff                             # then /reload
```
