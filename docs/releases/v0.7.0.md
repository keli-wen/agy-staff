# agy-staff 0.7.0 — Task orchestration with AGY

Adds `agy:lead`, a task orchestration skill for your agent. Within this workflow, the host delegates substantive work to `staffer` by default, selects specialist guidance when useful, and reserves `ask` for testing. The host retains decisions, review, and delivery. Existing persona skills and companion behavior are unchanged.

The jobs guidance covers follow-ups after completion, waiting for useful work, and canceling before an immediate change of direction. Follow-up briefs carry host decisions and account for partial work after interruption.

Includes the generated Pi lead entrypoint, minimal usage documentation, and a lead badge added to the existing homepage diagram. Real-model lead behavior and interrupted-conversation recovery remain unvalidated.
