# agy-staff 0.7.0 — Task orchestration with AGY

agy:lead, a task orchestration skill for your agent. The host delegates substantive work to AGY while owning key decisions, review, and final delivery. Invoke `/agy:lead` in Claude Code, `$agy:lead` in Codex, or `/skill:agy-lead` in Pi.

Lead defaults to `staffer`, using the brief to define work across research, analysis, writing, planning, and implementation. Select a specialist when requested or when its guidance materially helps. `ask` remains available for installation smoke tests or explicit testing; its command behavior is unchanged.

The guidance covers coherent assignments, relevant context and decisions, dependency-aware parallel work, evidence-based acceptance, and conversation reuse. It preserves the user's requested scope and stage, avoids duplicate work, and lets the host synthesize results. It adds no companion mode or scheduler. The homepage diagram shows lead within the current agent, with assignments and feedback flowing to AGY and results returning.

The shared jobs guidance explains follow-ups: continue completed conversations, wait when feedback can wait, or cancel and confirm termination before continuing an immediate change. Account for partial artifacts after interruption and supply decisions made in the host conversation.

Continuation targeting a conversation with a running background job returns immediately with exit `2`, the active job ID, and `prompt_accepted: false`. No prompt is sent or queued. This includes persona continuation flags and older jobs whose conversation has a running successor. Background registration rechecks under the state lock to reject competing continuations.

The guard covers background jobs recorded in the current repository, not external AGY processes or concurrent synchronous calls. Native AGY persistence determines what can be recovered after interruption; a conversation ID does not guarantee the last step was saved. Real-model lead behavior, efficiency, and interrupted-conversation recovery remain unvalidated.
