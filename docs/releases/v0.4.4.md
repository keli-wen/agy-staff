# agy-staff 0.4.4 — Implementer Continuation

Release date: 2026-08-30.

## Highlights

- `implement` no longer refuses a dirty Git workspace before starting.
- When `implement` starts on a dirty workspace, the companion adds a focused prompt section listing the pre-run `git status --porcelain` entries and instructing agy to treat them as user-owned context.
- `continue` can now resume an implement conversation after the previous implement run left a working-tree diff.
- The implementer prompt now allows agy itself to commit, push, or open/update a PR only when the task explicitly asks for that exact Git delivery; otherwise it leaves a reviewable working-tree diff.

## Verification

- Added black-box coverage for dirty-workspace prompt injection and implement continuation over its own dirty result.
- Ran a live `$agy:staffer` smoke across five temp-repo scenarios: clean edit, dirty workspace in-scope, continuation over an implementer-created dirty result, prompt-owned local commit delivery, and bounded dirty-status prompt injection.
