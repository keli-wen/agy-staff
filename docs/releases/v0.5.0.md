# agy-staff 0.5.0 — Gemini 3.8 Flash

Release date: 2026-09-02.

## Highlights

- **Gemini 3.8 Flash default update.** All persona defaults and the `flash` alias / `--effort` shorthand move from Gemini 3.7 Flash to Gemini 3.8 Flash, preserving the effort tier of every persona:
  - `ask`: `gemini-3.8-flash-low` (low effort, ~3s tool-free Q&A)
  - `staffer`: `gemini-3.8-flash-medium` (medium effort, general-purpose delegation)
  - `reviewer`: `gemini-3.8-flash-medium` (medium effort, code and plan reviews)
  - `researcher`: `gemini-3.8-flash-high` (high effort, deep research with sources)
  - `implementer`: `gemini-3.8-flash-high` (high effort, working-tree implementation)
- **No silent fallback on unsupported models.** When the installed `agy` does not support Gemini 3.8 Flash, the companion never silently downgrades or retries with an older model. It fails fast and actionable, querying `agy models` to report:
  1. The requested model
  2. Which models are available in the installed `agy` catalog
  3. The best same-effort compatible recommendation (e.g. `--model gemini-3.7-flash-high`)
  4. Notice that updating `agy` is preferred to use the latest default model
- **Preserved discovery errors and non-misclassification.** If `agy models` discovery itself fails, the original error is preserved alongside advice to run `agy models`. Auth, quota, network, and unrelated errors are never misclassified as unsupported model errors.
- **Synchronized visual assets.** Badge asset `assets/badges/model-gemini-3-8-flash.svg` generated via `scripts/gen_badges.py`, and `assets/design.svg` / `assets/design.png` updated to reflect Gemini 3.8 Flash.

## Upgrading

Both harnesses install a copy — pull 0.5.0 in yourself, then restart the harness so the skills load:

```bash
claude plugin marketplace update agy-staff && claude plugin update agy@agy-staff   # then restart Claude Code
```

```bash
codex plugin marketplace upgrade && codex plugin add agy@agy-staff                 # then restart Codex
```
